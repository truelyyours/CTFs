# Path Finder
Follow the `MAP.jpg` in that order and each image will reveal some par of flag either in bit planes or metadata.
E.g. `exiftool palms.jpg` revelas author as `amN0ZnZ7bjAxcl8=` which is decoded as `jctfv{n01r_`. **s.jpg** and **t.jpg** has clear base64 text which are decoded easily.
m.jpg is the more challinging.
